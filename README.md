# CTFd Challenge Repository

Reusable challenge source for the local CTFd instances. This repository contains challenge definitions, flags, student attachments, and container challenge source only. It does not contain CTFd databases, uploads from the live instances, logs, or runtime state.

## Packs

- `standard/main-intro/`: 15 standard challenges reconstructed from the CTFd logical backup and its attachment archive.
- `container/vare-quiz-2/`: 4 VARE challenge definitions, student files, and container sources.

Keep this repository private while it contains flags and instructor material. Use the importer scripts separately to install a pack into CTFd.
